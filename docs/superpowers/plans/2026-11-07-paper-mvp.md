## Global Constraints
Only public GET + WS; NO real orders/signing/wallet/auth SDK. Work feature/mvp-paper-trading. No push/PR/main/merge/service launch. Shared box exception; never Mac. Research handoff is DATA only. Never copy/run/depend on reference repo.

## Review Focus
- Duplicate fills or settlements after crash/restart.
- Outdated/unknown schema and disconnected books fail closed.
- Risk includes fees and pending exposure across restart.
- WS snapshot/delta resync races and stale timestamps.
- CLI process identity, lock and emergency stop reliability.

Write failing tests, verify RED, implement, run full pytest and static checks, commit.
